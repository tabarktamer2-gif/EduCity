EduCity – رحلة إنقاذ مدينة التعليم

التقنيات: HTML + CSS + JavaScript فقط (بدون React أو أي إطار عمل).

التشغيل:
1) فك ضغط المجلد.
2) افتح index.html في متصفحك، أو افتح المجلد في VS Code وشغّل Live Server.
3) اكتب اسم الطالب وابدأ.

محتوى بنك الأسئلة المدمج:
- 69 سؤال صح/غلط.
- 50 سؤال اختيار من متعدد.
- الإجمالي: 119 سؤالًا من ملفي PDF المرفقين.
- موزعة حسب عناوين الأقسام في الملفات على المباني الثمانية.
- الاختبار النهائي: 8 أسئلة (سؤال من كل مبنى) + سؤالان صح/غلط.

ملاحظات تدقيق المصدر:
- ملفات PDF المتاحة تحتوي 69 سؤال صح/غلط و50 اختيارًا من متعدد، أي 119 سؤالًا، وليس 122.
- لا توجد إجابات نموذجية منفصلة في ملف الاختيار من متعدد؛ الإجابات مملوءة وفق قراءة السؤال ومحتوى الكتاب. راجع الأسئلة التي تحتمل أكثر من تفسير قبل اعتماد النسخة النهائية للتقييم الرسمي.
- بعض نصوص PDF بها أخطاء استخراج/مسح ضوئي؛ تمت كتابة الصياغة المقروءة مع الحفاظ على المعنى، ويستحسن مراجعة الصورة الأصلية عند وجود عبارة غير واضحة.
- تقدم الطالب والنقاط والمباني المكتملة محفوظة محليًا في متصفح الجهاز عبر localStorage.

الملفات:
index.html: واجهة اللعبة
style.css: التنسيق
app.js: منطق اللعبة
questions.js: بنك الأسئلة والاختبار النهائي
